# 代码审查记录（docs/review）

本目录存放**代码审查与测试报告**记录，覆盖需求变更、模块实现、合并前的自检与互审。审查结论以仓库根 `AGENT.md` 的**领域红线**（量表以标准为准、AI 不诊断、同症多病多候选、术语合规、阈值受控、证据可解释、版本留痕、隐私最小必要、冲突不覆盖、转人工）为最高判据。

## 1. 编号规则

```
review-YYYYMMDD-NNN
```

- `YYYYMMDD`：审查日期（8 位数字）。
- `NNN`：同日序号，从 `001` 起递增，不足三位补零。
- 示例：`review-20261104-001`。

每条记录一个独立文件：`docs/review/review-YYYYMMDD-NNN.md`，文件名即编号，便于检索与引用。
