"""医护端视觉规范（**线 B**：结论与运营）

> 依据：2026-11-04 网络调研结论 + 仓库既有适老化约束。
> 本文件是医护端重做的**唯一依据**，实现时逐条对照。

## 1. 为什么现在的风格要推翻

现状（`frontend/tailwind.config.ts` + `globals.css`）：

- 大面积医疗蓝 `#1d4ed8` 作为按钮与强调色，页面被色块切割；
- 卡片 `rounded-1rem` + 双层阴影 `shadow-card`，内容浮在卡片上，层级噪音大；
- 每个信息点都包一层 `.card .card-pad`，一屏能看的信息很少；
- 进场动画 `fade-in-up` 叠加，正文用 18px 起的适老化字号——**这是老人端的需求，用在医护端就导致信息密度极低**。

结论：**老人端与医护端应该有两套视觉**，不是一套打补丁。
老人端（大字号、高对比、暖蓝、点击目标大）属线 A，不动；
医护端（信息密度高、克制、近黑+teal、无阴影）属线 B，本次重做。

## 2. 配色（Slate 中性 + 单一强调色）

调研结论：shadcn/ui 推荐以 **Slate** 作为中性底色，语义色只用于状态，**大面积不要上色**。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--c-bg` | `#ffffff` | 页面底色 |
| `--c-surface` | `#ffffff` | 区块底色 |
| `--c-muted` | `#f8fafc` | 表头、次级区块底色 |
| `--c-border` | `#e2e8f0` | 1px 分隔线（全站统一） |
| `--c-border-strong` | `#cbd5e1` | 输入框、强调边界 |
| `--c-fg` | `#0f172a` | 正文 |
| `--c-fg-muted` | `#64748b` | 辅助文字 |
| `--c-fg-subtle` | `#94a3b8` | 占位符、禁用 |
| `--c-primary` | `#0f172a` | **主按钮（近黑）**，不用彩色大按钮 |
| `--c-primary-hover` | `#1e293b` | 主按钮 hover |
| `--c-accent` | `#0d9488` | **teal-600**：链接、选中态、图表主色、数据强调 |
| `--c-accent-soft` | `#ccfbf1` | 选中行/高亮底色 |
| `--c-danger` | `#dc2626` | 急症、误报、删除 |
| `--c-warning` | `#d97706` | 待确认、降级 |
| `--c-success` | `#059669` | 已完成、通过 |

规则：
1. **一个页面只有一个强调色**（teal），其余靠灰阶与分隔线组织；
2. 不用彩色大色块做背景，除状态徽章外一律白底 + 1px 边框；
3. 语义色只出现在徽章、图表状态列、红旗提示里；
4. 颜色全部走 CSS 变量，禁止在组件里写死 hex（便于后续换肤与深色模式）。

## 3. 尺寸与排版

| 项 | 值 | 与老人端的差别 |
| --- | --- | --- |
| 正文 | 14px / 1.6 | 老人端 18px / 1.8 |
| 页面标题 | 18px / 600 | — |
| 区块标题 | 14px / 600，前置 1px 竖线 | — |
| 表格 | 13px，数字 `tabular-nums` | — |
| 辅助文字 | 12px / 1.5 | — |
| 圆角 | 8px（控件）/ 6px（徽章、输入） | 老人端 16px |
| 阴影 | `0 1px 2px rgba(15,23,42,.05)`，仅浮层 | 老人端无阴影 |
| 间距节奏 | 8 的倍数，区块间 24px，表格行 10px | 老人端 16~24px |

**动画**：医护端取消 `fade-in-up` 进场动画，只保留 120~150ms 的颜色/位移过渡。

## 4. 布局骨架

```text
┌──────────┬──────────────────────────────────────────────┐
│ 侧边栏    │ 顶部条：页面标题（18px）        右侧操作区     │
│ 216px    ├──────────────────────────────────────────────┤
│ 固定      │ 内容区：p-6，无卡片阴影，用 1px 分隔线分块     │
│ 图标+文字 │                                              │
│ 40px 项高 │ 表格为主，卡片只用于「成组指标」             │
└──────────┴──────────────────────────────────────────────┘
```

- 侧边栏：白底、右侧 1px 竖线，**不做成深色侧栏**（深色侧栏是"大后台"观感，简洁风里已过时）；
- 当前项：左侧 2px teal 竖条 + `--c-accent-soft` 底色 + `--c-fg` 文字，不使用彩色实心块；
- 内容区不使用 `.card .card-pad`（那是老人端的样式），改用 `.clin-section`（上边框 + 标题）。

## 5. 组件：直接抄 shadcn/ui

来源：**shadcn/ui**（MIT，https://github.com/shadcn-ui/ui），组件源码复制进本仓库 `src/components/ui/`，
依赖 Radix UI primitives + `class-variance-authority` + `clsx` + `tailwind-merge` + `lucide-react`（图标）。

需要的组件（复制后按本项目 token 微调颜色/圆角）：

| 组件 | 用途 |
| --- | --- |
| `button` | 主/次/幽灵/危险四种变体，主按钮用 `--c-primary` 近黑 |
| `badge` | 状态徽章：风险等级、复核状态、量表维度 |
| `card` | 只用于「成组指标」，**去掉阴影**、圆角 8px |
| `table` | 任务列表、患者列表、量表结果表 |
| `input` / `label` / `select` | 搜索与筛选（高度 32~36px，不是适老化的 48px） |
| `tabs` | 患者档案的五个页签 |
| `separator` | 区块分隔线 |
| `dropdown-menu` | 行内操作菜单 |
| `dialog` / `sheet` | 确认框与详情抽屉 |
| `tooltip` | 图标按钮说明 |
| `scroll-area` | 侧边栏与表格滚动区 |
| `skeleton` | 加载态 |

另有 `src/lib/utils.ts` 的 `cn()`（clsx + tailwind-merge）。

> 署名：shadcn/ui 为 MIT 协议，复制组件进仓库需在 `frontend/README` 或组件文件头保留版权声明。

## 7. 知识库可视化（`/staff/knowledge`）

- **组件不自己设计**：直接采用 GitHub 开源方案（选型见 `docs/research/2026-11-04-知识库可视化开源方案选型.md`），按其许可证要求保留署名；
- 数据来自后端 `GET /api/v1/knowledge/graph`（线 B 接口）：节点=疾病/症状/量表，边=引用(core/secondary)/关注项/同义；
- 交互：按类型过滤、搜索定位、点击节点看详情（关联病种、关联量表、鉴别问法）；
