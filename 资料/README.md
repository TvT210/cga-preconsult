# 资料区说明（原始资料 → 结构化资产）

> 本目录存放**收集到的原始资料**；系统真正使用的数据在 `docs/structured/`。
> 仓库 `TvT210/cga-preconsult` 是**公开仓库**，请遵守下面的入库规则。

## 目录约定

| 目录 | 放什么 | 入库 |
| --- | --- | --- |
| `标准原文/` | WS/T 888—2026、GB/T 42195、WS/T 802、WS/T 484、MZ/T 185 等标准 PDF | ❌ 不入库 |
| `指南共识/` | 各科室诊疗指南、专家共识 | ❌ 不入库 |
| `院内规范/` | 本院报告模板、随访规范、病案归档要求 | ❌ 不入库 |
| `笔记/` | 自己的摘录与要点（Markdown / txt） | ✅ 可入库，但**不要贴大段原文**，用自己的话转述 + 标注出处条款号 |

**文件名**：`来源机构-文件名-年份.扩展名`
例：`资料/指南共识/中华医学会-老年高血压诊疗指南-2023.pdf`

## ⚠️ 为什么原件不入库

标准与指南的 PDF 受版权保护。公开仓库直接收录它们存在法律风险，
且一旦推送就无法真正撤回（fork 会留副本）。

正确做法：
- 原件只留本地（或放团队内网/网盘，仓库里只留路径说明）；
- 入库的只有**结构化转写结果**（题库 JSON、疾病库 JSON）+ **出处元信息**（名称、发布机构、年份、版本、链接）；
- 报告与材料中引用条文时写条款号（如「WS/T 888—2026 附录B B.1」），不贴原文截图。

`.gitignore` 已排除 `资料/` 下的 PDF/DOCX/图片等二进制原件。
